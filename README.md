# WISE.UWWTD Public

Reported and compliance data for the Urban Waste Water Treatment Directive, reference years 2022 and 2024, for easier reuse.

**Official compliance data:** https://discomap.eea.europa.eu/uwwtd/registers/

Each zip holds CSV files with a header row. Anything marked `PROVISIONAL` (all of 2024) is under Member State review and may change. `FLAContact.csv` is left out because it holds personal data.
